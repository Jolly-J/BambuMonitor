# UI 表现层规范 (AGENTS.md)

本目录承载视图控制器、页面入口与状态分发模型。

---

## 1. 架构与状态流向

- **单一单向数据流（UDF）**：UI 仅通过 `viewModel.uiState` 观察单一不可变状态 `BambuUiState`。
- **事件上报**：用户所有操作均通过标准 Lambda 回调向 ViewModel 派发动作，UI 不维护独立的长周期业务逻辑。
- **窄屏与折叠屏自适应**：
  - 单列与双列工作台自适应，通过可用宽度弹性切换；
  - 严禁任何关键文字由于宽度过小发生不规则换行导致挤压。

---

## 2. 核心文件索引

- `BambuMonitorViewModel.kt`：状态聚合中心、设备切换与控制指令分发。
- `DashboardScreen.kt`：监视器主屏容器，提供自适应双列（>=600dp）与紧凑单列流式布局。
- `DeviceManagementDialog.kt`：自适应设备管理弹窗，支持局域网设备发现与手动配对。
- `theme/`：设计系统基石（G2 连续曲率超椭圆、微边框柔和底色、主题配色）。
- `components/`：业务原子卡片组件集。
