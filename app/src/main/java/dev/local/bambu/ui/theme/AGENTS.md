# UI 设计系统与美学基石规范 (AGENTS.md)

本目录承载整套 UI 美学核心，对标《小蝠》的工业级质感标准。

---

## 1. 核心美学规范

- **Apple G2 连续曲率超椭圆**：
  - 核心组件：`ContinuousCornerShape`；
  - 算法：采用平滑连续三次贝塞尔曲线替代传统圆形转角，曲率平缓过度无断层（Smoothing = 0.72f）。
- **SoftSurface 柔和微边框面板**：
  - 去除厚重浑浊的全局阴影；
  - 采用 `1.dp` 极细微透明轮廓线（`outlineVariant` 或 `accent.copy(alpha = 0.25f)`）；
  - 底色采用受控微弱着色（`accent.copy(alpha = 0.035f)`），保证在浅色与深色模式下均通透雅致。
- **色彩与品牌**：
  - 拓竹品牌绿（`#00AE42`）、深邃工业黑底（`#0B0F17`）、冷板灰浅色底（`#F8FAFC`）。
  - 热端暖橙（`#FF6D00`）、热床琥珀（`#F59E0B`）、降温风扇天空蓝（`#0EA5E9`）。
