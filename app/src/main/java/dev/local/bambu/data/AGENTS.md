# 数据仓储与持久化层规范 (AGENTS.md)

本目录承载打印机配对信息、历史连接与偏好设置的本地持久化。

---

## 1. 职能与约束

- **单一数据源**：`DeviceRepository` 是整个应用对已保存设备和选中设备 ID 的唯一访问入口。
- **线程安全与同步**：对 `SharedPreferences` 的读取必须具备容错机制（如 JSON 解析失败时返回空列表或默认安全状态）。
- **解耦原则**：不持有任何网络连接状态，仅负责数据持久化读写。

---

## 2. 核心文件索引

- `DeviceRepository.kt`：持久化多台拓竹打印机配置（ID、IP、访问码、型号、名称）及当前活跃设备。
